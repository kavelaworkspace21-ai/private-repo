# pip-audit vulnerability waivers  (Sprint 0 · S0.3)
#
# The CI "Dependency audit" step is BLOCKING: an unwaived known CVE in a runtime
# dependency fails the build. This file is the ONLY sanctioned escape hatch.
#
# Format: one PyPI advisory / CVE id per line (e.g. GHSA-xxxx-xxxx-xxxx or PYSEC-2024-123),
# optionally followed by whitespace and a comment. Blank lines and #-comments are ignored.
# Every waiver MUST carry a reason and, ideally, a review date — a waiver without a
# justification is a security hole with a passing build.
#
# Prefer fixing (upgrade the dependency) over waiving. Waive only when: the fix is not yet
# released, OR the vulnerable code path is provably unreachable in Juriscite. Re-review each
# waiver at every dependency bump.
#
# --- active waivers ---
